title: "You can start now"
date: 2026-05-26
---

You are a software engineer. It is brand new day and you picked a ticket (task) to work on.

You read the description. You don't understand. You read it again. You can't help but to complain why it is written such way. You question the words and sentences here and there. You try to understand what is needed, why it is needed and how you can do it. It gets clearer and clearer. There are still open points in your mind regarding why it is exactly needed and from which context does it come from. You decide to ask them later as the task is clear now. You can start now.

You jump into the codebase. Trying to decide which part of the codebase should be changed. It has been a while since you worked on this end of the codebase. You read the file. You don't understand. You skim the file to understand you are actually looking at the correct thing. It is the correct file. You read it again. You don't understand. You can't help but whisper yourself 'but why (is it written this way)?'. It gets sense as you spend more time on it, either by yourself or by getting help. Okay, you got it now. It is all clear. That method has to be extended to support the functionality. You can start now.

You get yourself a cup of coffee, sit to the end of your chair and pull the keyboard to yourself. You are ready to implement. Huh, should you write a unit test? Perhaps you should follow TDD. You first ask the agent to write a test for you. However it looks really odd, so you decide to write yourself. It is difficult to write though. How was the syntax? You open other test files to understand the syntax. You copy-paste and try to rewrite the necessary parts. You run the test but it raises an error. It doesn't make any sense. Oh... You forgot to mock one method call. You run the test again and something else is not working. You pass the error message directly to your AI agent and you look outside the window while waiting for the agent's response. Agent responds back and fixes the test with another mock. The test is ready, now it is time to implement the functionality. You can finally start now.

It takes 2 minutes to write the functionality. The test passes. It takes another 5 mins to do a manual test. You take screenshots from the test and open up the PR with them.

You look to the screen. It all makes sense now. Why it is needed, what does it change and how to implement it. The ticket description, the codebase and the test are all fine actually. The test that the agent first suggested was the exactly what you've needed. Then why did you feel that way? You turn to the window, the sky is blue. Sun is out. You hear the voices coming from the street. You think that maybe you were the problem there. You could have learned about the syntax of your test framework, instead of blindly copy-pasting the one implemented before. You could have a look at that part of the codebase and try to learn more about it.
